Farben-Rennen

Jede:r bekommt eine Autofarbe. Wer sie sieht, tippt – wer zuerst am Ziel ist, gewinnt.

Wer fährt mit?

Mindestens zwei Namen. Die Farben werden danach zufällig verteilt – das spart die Diskussion.

    Ziel 10

    🏁 –

      Tippt auf eure Farbe, sobald ihr so ein Auto seht.

      So wird gespielt
      • Jede:r bekommt eine Autofarbe zugelost.
      • Wer ein Auto in seiner Farbe sieht, tippt auf die eigene Kachel.
      • Nur entgegenkommende Autos zählen – sonst wird’s zu einfach.
      • Wer zuerst das Ziel erreicht, gewinnt die Runde.
      • Verzählt? „Rückgängig“ nimmt den letzten Tipp zurück.
      • Mit dem Code aus den Einstellungen spielt ein zweites Auto dieselbe Verteilung.
