Erzählwürfel

Würfeln, und dann reihum eine Geschichte bauen – jedes Symbol muss vorkommen.

Es war einmal …

    Tippe ein Symbol an, wenn es in der Geschichte vorkam.

    So wird gespielt
    • Würfeln, dann fängt jemand mit dem Satzanfang an.
    • Wer dran ist, baut ein Symbol in die Geschichte ein und tippt es an.
    • Dann ist die nächste Person dran – bis alle Symbole verbraucht sind.
    • Es gibt keine Punkte und keine falschen Geschichten.
    • Mit dem Code aus den Einstellungen bekommt ein zweites Handy dieselben Symbole.

    Einstellungen

    Wie viele Symbole
    Gemeinsam spielen

    –

    Gleicher Code = gleiche Symbole. Praktisch, wenn zwei Autos zusammen unterwegs sind.

    Alles wird nur lokal auf diesem Gerät gespeichert.
