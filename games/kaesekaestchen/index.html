Käsekästchen

Abwechselnd eine Linie ziehen. Wer ein Kästchen schließt, darf nochmal.

Wer spielt gegen wen?

Zwei Namen. Gespielt wird abwechselnd auf diesem Handy.

    – 0

    – 0

    –

    Vorbei

    –

    So wird gespielt
    • Abwechselnd eine Linie zwischen zwei Punkten ziehen.
    • Wer die vierte Seite eines Kästchens zieht, bekommt es – und ist gleich nochmal dran.
    • Das geht so weiter, solange man Kästchen schließt.
    • Wenn alle Linien gezogen sind, gewinnt, wer mehr Kästchen hat.
