    …

    Tippt auf die Person, auf die die meisten zeigen.

      So wird gespielt
      • Eine Person liest die Frage laut vor.
      • Bei „drei, zwei, eins“ zeigen alle gleichzeitig auf jemanden.
      • Wer die meisten Finger abbekommt, tippt sich selbst an und bekommt den Punkt.
      • Unentschieden? Einfach überspringen – oder beiden einen Punkt geben.
      • Mit dem Code aus den Einstellungen bekommen alle Handys dieselben Fragen.
